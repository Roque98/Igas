📁 Configuración de Storage

Sistema de almacenamiento de adjuntos para tickets - iGAS Helpdesk

📋 Resumen

Esta guía te ayudará a configurar el almacenamiento de archivos adjuntos en Supabase Storage para el sistema de tickets de iGAS Helpdesk.

✓ ¿Qué vamos a configurar?
  • Bucket privado "ticket-attachments" para almacenar archivos
  • Políticas de seguridad (Storage Policies) para control de acceso
  • Estructura de carpetas organizada por ticket_id
  • Límites de tamaño y tipos de archivo permitidos

Paso a Paso

1 Crear el Bucket en Supabase

  1. Inicia sesión en Supabase Dashboard
  2. Ve a la sección Storage en el menú lateral
  3. Haz clic en "New bucket"
  4. Configura el bucket con los siguientes valores:
Configuración Valor
Nombre ticket-attachments
Public ❌ No (privado)
File size limit 10 MB
Allowed MIME types image/*, application/pdf, application/msword, application/vnd.*, text/plain, application/zip
💡 Nota: El bucket debe ser privado para que solo usuarios autenticados con los permisos correctos puedan acceder a los archivos.

2 Aplicar Políticas de Storage

Las políticas de Storage controlan quién puede subir, ver, modificar o eliminar archivos.

  1. En Supabase Dashboard, ve a Storage > Policies
  2. Selecciona la tabla objects
  3. Haz clic en "New Policy"
  4. Ejecuta las siguientes políticas SQL una por una:

🔹 Política 1: Subir archivos

CREATE POLICY "Users can upload files to their tickets"
ON storage.objects FOR INSERT
WITH CHECK (
  bucket_id = 'ticket-attachments'
  AND auth.uid() IS NOT NULL
  AND (
    EXISTS (
      SELECT 1 FROM public.tickets t
      WHERE t.id::text = (storage.foldername(name))[1]
      AND (
        t.responsable_id = auth.uid()
        OR t.creado_por = auth.uid()
        OR EXISTS (
          SELECT 1 FROM public.ticket_participantes tp
          WHERE tp.ticket_id = t.id AND tp.usuario_id = auth.uid()
        )
      )
    )
    OR EXISTS (
      SELECT 1 FROM public.profiles p
      WHERE p.id = auth.uid()
      AND p.rol_id IN (SELECT id FROM public.roles WHERE nombre = 'Administrador')
    )
  )
);

3 Verificar la Configuración

Ejecuta la siguiente consulta en el SQL Editor de Supabase para verificar que las políticas se crearon correctamente:

SELECT
  policyname,
  cmd,
  qual,
  with_check
FROM pg_policies
WHERE schemaname = 'storage'
AND tablename = 'objects'
ORDER BY policyname;
✓ Deberías ver 4 políticas:
  • Users can upload files to their tickets (INSERT)
  • Users can view files from their tickets (SELECT)
  • Users can update files from their tickets (UPDATE)
  • Users can delete files from their tickets (DELETE)

📂 Estructura de Archivos

Los archivos se organizan de la siguiente manera:

ticket-attachments/
  └── {ticket_id}/
      ├── {timestamp}_{filename}.pdf
      ├── {timestamp}_{filename}.jpg
      └── ...
Ejemplo de ruta completa:
ticket-attachments/a1b2c3d4-e5f6-7890-abcd-ef1234567890/1736611200_cotizacion.pdf

Ventajas de esta estructura:

  • ✓ Fácil de organizar por ticket
  • ✓ El timestamp evita colisiones de nombres
  • ✓ Facilita la limpieza cuando se elimina un ticket
  • ✓ Compatible con las políticas de seguridad

📄 Tipos de Archivo Permitidos

Categoría Extensiones MIME Type
Imágenes .jpg, .jpeg, .png, .gif, .webp image/*
PDF .pdf application/pdf
Word .doc, .docx application/msword, application/vnd.openxmlformats-officedocument.wordprocessingml.document
Excel .xls, .xlsx application/vnd.ms-excel, application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Texto .txt text/plain
Comprimidos .zip application/zip
⚠️ Límites:
  • Tamaño máximo por archivo: 10 MB
  • Total de almacenamiento: Según el plan de Supabase

💻 Implementación en Angular

Ejemplo de servicio para subir archivos:

// ticket-attachment.service.ts
import { Injectable } from '@angular/core';
import { SupabaseService } from './supabase.service';

@Injectable({
  providedIn: 'root'
})
export class TicketAttachmentService {
  constructor(private supabase: SupabaseService) {}

  async uploadAttachment(ticketId: string, file: File): Promise<string> {
    // Generar nombre único con timestamp
    const timestamp = Date.now();
    const fileName = `${timestamp}_${file.name}`;
    const filePath = `${ticketId}/${fileName}`;

    // Subir archivo a Storage
    const { data, error } = await this.supabase.client.storage
      .from('ticket-attachments')
      .upload(filePath, file);

    if (error) {
      throw new Error(`Error al subir archivo: ${error.message}`);
    }

    // Registrar en la tabla ticket_adjuntos
    const { error: dbError } = await this.supabase.client
      .from('ticket_adjuntos')
      .insert({
        ticket_id: ticketId,
        nombre_archivo: file.name,
        ruta_storage: filePath,
        tipo_archivo: file.type,
        tamanio_bytes: file.size
      });

    if (dbError) {
      throw new Error(`Error al registrar adjunto: ${dbError.message}`);
    }

    return data.path;
  }

  async downloadAttachment(filePath: string): Promise<Blob> {
    const { data, error } = await this.supabase.client.storage
      .from('ticket-attachments')
      .download(filePath);

    if (error) {
      throw new Error(`Error al descargar archivo: ${error.message}`);
    }

    return data;
  }

  async deleteAttachment(filePath: string, adjuntoId: string): Promise<void> {
    // Eliminar de Storage
    const { error: storageError } = await this.supabase.client.storage
      .from('ticket-attachments')
      .remove([filePath]);

    if (storageError) {
      throw new Error(`Error al eliminar archivo: ${storageError.message}`);
    }

    // Eliminar registro de la base de datos
    const { error: dbError } = await this.supabase.client
      .from('ticket_adjuntos')
      .delete()
      .eq('id', adjuntoId);

    if (dbError) {
      throw new Error(`Error al eliminar registro: ${dbError.message}`);
    }
  }

  async getAttachmentUrl(filePath: string): Promise<string> {
    const { data } = await this.supabase.client.storage
      .from('ticket-attachments')
      .createSignedUrl(filePath, 3600); // URL válida por 1 hora

    return data?.signedUrl || '';
  }
}
