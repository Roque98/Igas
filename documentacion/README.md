## 🛠️ Stack Tecnológico

- **Framework**: Angular 21
- **UI Template**: Datta Able Free Angular Admin Template v6.3.0
- **Backend**: Supabase
- **Estilos**: SCSS, Bootstrap 5
- **Control de Versiones**: Git + GitFlow

## 📝 Notas Importantes

- Este proyecto sigue el flujo GitFlow
- La rama `dev` es para desarrollo
- La rama `master` es para producción
- Nunca hacer push directo a `master`
