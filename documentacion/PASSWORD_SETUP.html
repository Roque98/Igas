🔐 Configuración de Políticas de Contraseña - iGAS Helpdesk

📋 Objetivo: Configurar políticas de seguridad robustas para las contraseñas de usuarios del sistema iGAS Helpdesk, protegiendo contra acceso no autorizado y ataques de fuerza bruta.

⚡ Configuración Rápida (Dashboard)

FÁCIL Esta configuración se hace directamente en el dashboard de Supabase sin necesidad de SQL.

1 Acceder a Supabase Dashboard

  1. Ve a https://supabase.com/dashboard
  2. Selecciona tu proyecto: iGAS Helpdesk
  3. En el menú lateral, haz clic en Authentication

2 Configurar Política de Contraseñas

  1. Dentro de Authentication, haz clic en Policies
  2. Busca la sección Password Policy
  3. Configura los siguientes valores:
    • Minimum password length: 8 caracteres
    • Require uppercase and lowercase: ✅ Activado
    • Require numbers: ✅ Activado
    • Require special characters: ✅ Activado
  4. Haz clic en Save
✅ Resultado: Las contraseñas ahora deben tener:
  • Mínimo 8 caracteres
  • Al menos una letra mayúscula (A-Z)
  • Al menos una letra minúscula (a-z)
  • Al menos un número (0-9)
  • Al menos un carácter especial (!@#$%^&*...)

3 Configurar Rate Limiting

  1. En el menú Authentication, haz clic en Rate Limits
  2. Configura los siguientes límites:
Endpoint Límite Período Propósito
/auth/v1/token 5 requests 15 minutos Prevenir ataques de fuerza bruta en login
/auth/v1/recover 3 requests 1 hora Limitar recuperación de contraseña
/auth/v1/user 5 requests 1 hora Proteger actualizaciones de perfil
⚠️ Importante: Estos límites protegen contra ataques automatizados pero no afectan el uso normal. Los usuarios legítimos rara vez exceden estos límites.

🗄️ Configuración Avanzada (SQL)

MEDIO SQL Para funcionalidades adicionales como historial de contraseñas y detección de ataques.

4 Ejecutar Script SQL de Políticas

  1. Ve a SQL Editor en el menú lateral de Supabase
  2. Haz clic en + New query
  3. Copia y pega el contenido del archivo: 
    database/migrations/09_password_policies.sql
  4. Haz clic en Run
  5. Verifica que no haya errores en la consola
✅ Funcionalidades agregadas:
  • 📜 Historial de contraseñas (previene reutilización)
  • 🚫 Detección de intentos fallidos de login
  • 🔒 Bloqueo automático después de 5 intentos fallidos
  • ⏰ Seguimiento de expiración de contraseñas
  • 📊 Vistas de monitoreo y estadísticas

📋 Verificación de Implementación

  • Longitud mínima de 8 caracteres configurada
  • Requisitos de complejidad habilitados (mayúsculas, minúsculas, números, especiales)
  • Rate limiting configurado en endpoints de autenticación
  • Script SQL de políticas avanzadas ejecutado
  • Verificar funcionamiento con usuario de prueba

🧪 Pruebas de Validación

Prueba 1: Contraseña Débil

Intenta crear un usuario con contraseña débil:

  • password → ❌ Debe fallar (sin mayúsculas, números, especiales)
  • 12345678 → ❌ Debe fallar (solo números)
  • Password → ❌ Debe fallar (sin números ni especiales)

Prueba 2: Contraseña Válida

Estas contraseñas deben ser aceptadas:

  • Password123! → ✅ Válida
  • iGAS@2026Test → ✅ Válida
  • Secure#Pass99 → ✅ Válida

Prueba 3: Rate Limiting

Verifica que el bloqueo funciona:

  1. Intenta hacer login 6 veces con contraseña incorrecta
  2. El 6to intento debe ser bloqueado con error 429 (Too Many Requests)
  3. Espera 15 minutos y vuelve a intentar
  4. El login debe funcionar nuevamente

📊 Monitoreo y Reportes

🔍 Consultas SQL útiles para monitoreo:

Ver usuarios bloqueados actualmente

SELECT *
FROM blocked_users
WHERE is_currently_blocked = true;

Ver contraseñas próximas a expirar (15 días)

SELECT
  nombre_completo,
  email,
  rol,
  days_until_expiry
FROM passwords_expiring_soon
WHERE days_until_expiry <= 15
ORDER BY days_until_expiry ASC;

Estadísticas de intentos fallidos últimas 24h

SELECT *
FROM failed_login_stats
WHERE date >= CURRENT_DATE - INTERVAL '7 days'
ORDER BY date DESC;

Limpiar intentos fallidos antiguos

SELECT cleanup_old_failed_attempts();

🛡️ Políticas por Rol

Rol Longitud Mínima Expiración 2FA
Administrador 12 caracteres 60 días Obligatorio
Coordinador/Supervisor 10 caracteres 90 días Recomendado
